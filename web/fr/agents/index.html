Donnez une boîte mail à vos agents IA

Avec le CLI shalom, chaque agent a sa propre adresse @shalomail.com. Il reçoit, lit et envoie de vrais e-mails, depuis Shalom ou n'importe où, et chaque commande parle JSON. La clé privée de la boîte naît sur la machine de l'agent et n'en sort jamais.

Créer un compte gratuitDéjà un compte ? Ouvrez vos agents

Commencez en trois commandes

  1. Installez le CLI. Il faut Node.js 20 ou plus récent.

    npm install -g shalomail

  2. Connectez le terminal à votre compte. La commande ouvre une page Shalom, et vous confirmez en un clic.

    shalom login

  3. Créez la boîte de votre agent. Sa clé privée est générée et gardée sur cette machine.

    shalom agents create tonnom-bot

Lire, répondre et envoyer

Chaque commande accepte --json : votre agent lit la sortie sans deviner. Les identifiants peuvent être raccourcis à leurs 8 premiers caractères.

shalom inbox --json
shalom read 3f9c2a1b --json
shalom reply 3f9c2a1b --text "Bien reçu, merci."
shalom send --to ana@example.com --subject "Rapport hebdomadaire" \
  --text-file report.md --attach report.pdf

Réagir à chaque nouvel e-mail

watch attend les nouveaux e-mails et lance votre programme une fois par message, avec le message en JSON sur l'entrée standard.

shalom watch --exec "python agent.py" --mark-read

Le JSON contient id, from, to, cc, subject, date, text, html, messageId, verifiedSender et la liste des pièces jointes. L'environnement reçoit aussi SHALOM_MESSAGE_ID, SHALOM_FROM et SHALOM_SUBJECT.

Le faire tourner sur un serveur

Exportez la boîte en une seule variable et utilisez-la sur n'importe quel serveur, conteneur ou CI. Gardez-la secrète : elle contient la clé privée.

shalom agents export tonnom-bot@shalomail.com
SHALOM_AGENT_TOKEN=shalom_agent_... shalom inbox --json

Sécurité

  • La clé privée de chaque boîte reste sur la machine de l'agent. Le serveur garde les e-mails scellés et ne peut pas les lire.
  • La clé de votre compte ne fait que créer et supprimer des boîtes d'agent. La clé de chaque boîte ne lit et n'envoie que par elle. Vous pouvez changer ou supprimer n'importe laquelle à tout moment.
  • Entre adresses Shalom, l'e-mail voyage scellé de bout en bout et l'expéditeur est vérifié. Vers les autres fournisseurs, il part comme un e-mail normal.

Toutes les commandes

shalom login
Connecte ce terminal à votre compte via le navigateur.
shalom agents list
Liste vos boîtes d'agent et votre offre.
shalom agents create <name>
Crée <nom>@shalomail.com, avec la clé privée sur cette machine.
shalom agents delete <address>
Supprime la boîte et tous ses e-mails. Il faut que la boîte soit enregistrée sur cette machine ; l'adresse reste réservée pour vous.
shalom agents rotate <address>
Émet une nouvelle clé API pour la boîte. L'ancienne cesse de fonctionner.
shalom agents export <address>
Affiche SHALOM_AGENT_TOKEN, pour faire tourner la boîte ailleurs.
shalom plan
Affiche votre offre et le nombre de boîtes utilisées.
shalom upgrade
Ouvre la page des offres dans l'app.
shalom inbox
Liste les messages d'un dossier. --unread n'affiche que les non lus.
shalom read <id>
Ouvre un message. --save-attachments enregistre les fichiers.
shalom send
Envoie un message, avec le texte en option, dans un fichier ou sur l'entrée standard, et des pièces jointes.
shalom reply <id>
Répond dans la même conversation. --all répond à tous.
shalom move <id> --to <folder>
Déplace vers la réception, les archives, le spam ou la corbeille.
shalom mark <id> --read
Marque comme lu ou non lu, suivi ou non.
shalom watch
Attend les nouveaux e-mails. --exec lance une commande pour chaque message.

Lancez shalom --help pour toutes les options. Toutes les commandes acceptent --json, et --as <adresse> pour choisir la boîte.

Shalom Mail (shalomail.com) est un service d’e-mail chiffré qui fonctionne dans le navigateur. Les e-mails stockés sont verrouillés par une clé que seul votre mot de passe déverrouille, et entre comptes Shalom tout est chiffré de bout en bout.
