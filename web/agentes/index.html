Dê uma caixa de e-mail para seus agentes de IA

Com o CLI shalom, cada agente ganha o próprio endereço @shalomail.com. Ele recebe, lê e envia e-mail de verdade, do Shalom ou de qualquer lugar, e todo comando fala JSON. A chave privada da caixa nasce na máquina do agente e nunca sai dela.

Criar conta grátisJá tem conta? Abra seus agentes

Comece em três comandos

  1. Instale o CLI. Ele precisa do Node.js 20 ou mais novo.

    npm install -g shalomail

  2. Conecte o terminal à sua conta. O comando abre uma página do Shalom, e você confirma com um clique.

    shalom login

  3. Crie a caixa do seu agente. A chave privada dela é gerada e guardada nesta máquina.

    shalom agents create seunome-bot

Ler, responder e enviar

Todo comando aceita --json, para o agente ler a saída sem adivinhar. Os ids podem ser encurtados para os 8 primeiros caracteres.

shalom inbox --json
shalom read 3f9c2a1b --json
shalom reply 3f9c2a1b --text "Recebido, obrigado."
shalom send --to ana@example.com --subject "Relatório semanal" \
  --text-file report.md --attach report.pdf

Reagir a cada e-mail novo

O watch espera os e-mails novos e roda o seu programa uma vez por mensagem, com a mensagem em JSON na entrada padrão.

shalom watch --exec "python agent.py" --mark-read

O JSON traz id, from, to, cc, subject, date, text, html, messageId, verifiedSender e a lista de anexos. O ambiente recebe também SHALOM_MESSAGE_ID, SHALOM_FROM e SHALOM_SUBJECT.

Rodar num servidor

Exporte a caixa numa variável só e use em qualquer servidor, contêiner ou CI. Guarde como segredo: ela contém a chave privada.

shalom agents export seunome-bot@shalomail.com
SHALOM_AGENT_TOKEN=shalom_agent_... shalom inbox --json

Segurança

  • A chave privada de cada caixa fica na máquina do agente. O servidor guarda os e-mails lacrados e não consegue ler.
  • A chave da sua conta só cria e apaga caixas de agente. A chave de cada caixa só lê e envia por ela. Dá para trocar ou apagar qualquer uma a qualquer hora.
  • Entre endereços Shalom, o e-mail vai lacrado de ponta a ponta e o remetente é conferido. Para outros provedores, vai como e-mail comum.

Todos os comandos

shalom login
Conecta este terminal à sua conta pelo navegador.
shalom agents list
Lista suas caixas de agente e o seu plano.
shalom agents create <name>
Cria <nome>@shalomail.com, com a chave privada nesta máquina.
shalom agents delete <address>
Apaga a caixa e todos os e-mails dela. Precisa da caixa salva nesta máquina; o endereço continua reservado para você.
shalom agents rotate <address>
Gera uma chave de API nova para a caixa. A antiga para de valer.
shalom agents export <address>
Mostra o SHALOM_AGENT_TOKEN, para rodar a caixa em outro lugar.
shalom plan
Mostra o seu plano e quantas caixas você usa.
shalom upgrade
Abre a página de planos no app.
shalom inbox
Lista as mensagens de uma pasta. --unread mostra só as não lidas.
shalom read <id>
Abre uma mensagem. --save-attachments salva os arquivos.
shalom send
Envia uma mensagem, com o texto num parâmetro, num arquivo ou na entrada padrão, e anexos.
shalom reply <id>
Responde na mesma conversa. --all responde a todos.
shalom move <id> --to <folder>
Move para entrada, arquivo, spam ou lixeira.
shalom mark <id> --read
Marca como lida ou não lida, com ou sem estrela.
shalom watch
Espera e-mails novos. --exec roda um comando para cada mensagem.

Rode shalom --help para ver todas as opções. Todo comando aceita --json, e --as <endereço> para escolher a caixa.

O Shalom Mail (shalomail.com) é um serviço de e-mail criptografado que funciona no navegador. Os e-mails guardados ficam trancados com uma chave que só existe no seu aparelho, e entre contas Shalom tudo vai de ponta a ponta.
