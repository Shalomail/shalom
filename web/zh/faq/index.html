常见问题

关于 Shalom Mail（shalomail.com 上的加密邮箱服务）的简短、直接的解答。

账户

Shalom Mail 是什么？

Shalom Mail 是一个在浏览器中使用的加密邮箱服务，网址是 shalomail.com。账户免费，含 1 GB 空间和一个 @shalomail.com 地址。存储的邮件用只存在于你设备上的密钥锁住，Shalom 账户之间的邮件端到端加密，AI 智能体也可以拥有自己的邮箱。

Shalom Mail 免费吗？

免费。邮箱账户免费，含 1 GB 存储空间和一个 @shalomail.com 地址，没有广告。付费套餐只面向需要 2 个以上 AI 智能体邮箱的用户。

注册需要手机号或身份证件吗？

不需要。你只需选择地址和密码，Shalom 不要求手机号，也不要求身份证件。在第一个邮箱打开之前，它会请你提供一个其他服务的恢复邮箱：忘记密码时，你就通过它回到账户。服务器锁定保存它，只在给你发送链接时使用。

可以给使用 Gmail 或 Outlook 的人发邮件吗？

可以。Shalom 地址可以与任何邮箱服务互发邮件，例如 Gmail、Outlook、iCloud 或 Yahoo，对方收到的是普通邮件。Shalom 账户之间则是端到端加密。

需要安装应用吗？

不需要。Shalom Mail 在电脑和手机的浏览器中使用，无需安装任何东西。AI 智能体邮箱通过 shalom CLI 或 Node SDK 使用。

Shalom Mail 支持哪些语言？

15 种语言：葡萄牙语、英语、西班牙语、法语、德语、意大利语、俄语、乌克兰语、土耳其语、希伯来语、阿拉伯语、印地语、中文、日语和韩语。

可以删除我的账户吗？

可以。写信至 contato@shalomail.com，账户会连同存储的邮件和账户数据一起删除。基础设施的备份可能需要几天才会过期。

隐私与加密

Shalom 能读我的邮件吗？

不能读你存储的邮件。每封邮件都用只存在于你设备上的密钥密封，服务器保存它却无法打开。来自其他服务的邮件在到达、尚未密封的那一刻，服务器可以读取；你发往其他服务的邮件则以普通邮件形式发出。

加密是如何工作的

Shalom Mail 是端到端加密的吗？

在 Shalom 账户之间是的。邮件在发件人的设备上密封，只在收件人的设备上打开，连发件人都对服务器隐藏。与其他邮箱服务之间无法做到，因为普通邮件以未加密的形式传输，所以 Shalom 会在这些邮件到达的那一刻将其密封。

加密是如何工作的

忘记密码会怎样？

存储的邮件无法恢复，因为只有你的密码能打开你的密钥，而 Shalom 没有副本。通过恢复邮箱，你可以设置新密码并保留你的地址，但邮箱会从空开始。

Shalom Mail 使用什么加密？

每封存储的邮件使用 X25519 密钥配合 HKDF-SHA256 和 AES-256-GCM，你设备上的密码使用 Argon2id，密封发件人使用 Ed25519 证书，Shalom 账户之间的匿名投递使用 RSA 盲签名。

加密是如何工作的

它使用 PGP 吗？

不使用。Shalom 有自己的格式，基于 X25519、HKDF-SHA256 和 AES-256-GCM，不使用 PGP 密钥。发往其他邮箱服务的邮件以普通邮件形式发出。

有广告或跟踪吗？

没有。没有广告，也没有广告、分析或跟踪类 Cookie，你的邮件也不会被用来训练任何东西。会暗中报告你何时打开邮件的图片会被拦截，冒充的发件人会以琥珀色标出。

Shalom 会向政府部门提供数据吗？

只在有有效法院命令时才会。服务器持有哪些数据，隐私政策中有列明。存储邮件的内容始终是加密的，而 Shalom 没有密钥。

隐私政策

面向 AI 智能体的邮箱

怎样给 AI 智能体一个自己的邮箱地址？

用 npm install -g shalomail 安装 shalom CLI，用 shalom login 把它连接到你的账户并在浏览器中确认，然后带上名字运行 shalom agents create。智能体会得到 name@shalomail.com，可以阅读、回复和发送真实邮件，输出为 JSON。

面向 AI 智能体的邮箱

AI 智能体邮箱怎么收费？

每个账户免费提供 2 个。Agents 5 每月 4.99 美元，最多 5 个；Agents 12 每月 9.99 美元，最多 12 个；Unlimited 每月 49.90 美元，不限邮箱数量，每天最多新建 250 个。套餐按月计费，通过 Stripe 收费，可随时取消。

Shalom 能读我的智能体的邮件吗？

不能读它们存储的邮件。每个智能体邮箱都有自己的私钥，在你运行 CLI 或 SDK 的机器上生成，服务器以密封形式保存它的邮件。你的账户密钥可以创建和删除智能体邮箱，但无法打开它们。

有 API 或 SDK 吗？

有。npm 上的 shalomail 包既是 CLI，也是 Node SDK，提供 Agent 和 Account 两个类，此外还有 HTTP API。加密始终在你这一侧完成。

智能体能自动响应新邮件吗？

能。shalom watch --exec 会为每封新邮件运行一次你的程序，并把邮件以 JSON 形式传入标准输入；SDK 中的 agent.watch() 作用相同。目前还没有 webhooks。

智能体能给 Shalom 以外的人发邮件吗？

能，以普通邮件形式发送。发往外部地址时，每个智能体邮箱第一周每天最多发给 20 位收件人，之后每天最多 100 位。Shalom 地址之间则是端到端加密，并会验证发件人。
