给你的 AI 智能体一个邮箱

借助 shalom CLI，每个智能体都有自己的 @shalomail.com 地址。它可以收取、阅读和发送来自 Shalom 或任何地方的真实邮件，每条命令都支持 JSON。邮箱的私钥在智能体的机器上生成，永远不会离开那里。

免费创建账户已有账户？打开你的智能体

三条命令即可开始

  1. 安装 CLI。需要 Node.js 20 或更高版本。

    npm install -g shalomail

  2. 把终端连接到你的账户。命令会打开一个 Shalom 页面，你点一下确认即可。

    shalom login

  3. 为你的智能体创建邮箱。它的私钥在这台机器上生成并保存。

    shalom agents create yourname-bot

阅读、回复和发送

每条命令都支持 --json，让智能体无需猜测即可读取输出。消息 ID 可以缩短为前 8 个字符。

shalom inbox --json
shalom read 3f9c2a1b --json
shalom reply 3f9c2a1b --text "已收到，谢谢。"
shalom send --to ana@example.com --subject "每周报告" \
  --text-file report.md --attach report.pdf

对每封新邮件做出反应

watch 会等待新邮件，并为每封邮件运行一次你的程序，邮件以 JSON 形式写入标准输入。

shalom watch --exec "python agent.py" --mark-read

JSON 包含 id, from, to, cc, subject, date, text, html, messageId, verifiedSender 以及附件列表。环境变量中还有 SHALOM_MESSAGE_ID、SHALOM_FROM 和 SHALOM_SUBJECT。

在服务器上运行

把邮箱导出为一个变量，就能在任何服务器、容器或 CI 中使用。请把它当作机密保存：其中包含私钥。

shalom agents export yourname-bot@shalomail.com
SHALOM_AGENT_TOKEN=shalom_agent_... shalom inbox --json

安全

  • 每个邮箱的私钥都留在智能体的机器上。服务器以密封形式保存邮件，无法读取。
  • 你的账户密钥只能创建和删除智能体邮箱。每个邮箱的密钥只能通过该邮箱阅读和发送。任何密钥都可以随时更换或删除。
  • 在 Shalom 地址之间，邮件端到端密封传输，并验证发件人。发往其他邮箱服务时，按普通邮件发送。

全部命令

shalom login
通过浏览器把这个终端连接到你的账户。
shalom agents list
列出你的智能体邮箱和套餐。
shalom agents create <name>
创建 <name>@shalomail.com，私钥保存在这台机器上。
shalom agents delete <address>
删除邮箱及其中的所有邮件。需要这台机器上保存着该邮箱；该地址仍为你保留。
shalom agents rotate <address>
为邮箱签发新的 API 密钥，旧密钥随即失效。
shalom agents export <address>
输出 SHALOM_AGENT_TOKEN，以便在别处运行该邮箱。
shalom plan
显示你的套餐和已使用的邮箱数量。
shalom upgrade
在应用中打开套餐页面。
shalom inbox
列出某个文件夹中的邮件。--unread 只显示未读邮件。
shalom read <id>
打开一封邮件。--save-attachments 保存附件。
shalom send
发送邮件，正文可来自参数、文件或标准输入，并可添加附件。
shalom reply <id>
在同一会话中回复。--all 回复所有人。
shalom move <id> --to <folder>
移动到收件箱、归档、垃圾邮件或废纸篓。
shalom mark <id> --read
标记为已读或未读，加星或取消星标。
shalom watch
等待新邮件。--exec 为每封邮件运行一条命令。

运行 shalom --help 查看所有选项。所有命令都支持 --json，并可用 --as <地址> 选择邮箱。

Shalom Mail（shalomail.com）是一个在浏览器中使用的加密邮箱服务。存储的邮件用只有你的密码能解开的密钥锁住，Shalom 账户之间的邮件全程端到端加密。
