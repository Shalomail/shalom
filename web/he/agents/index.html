תנו לסוכני ה-AI שלכם תיבת דואר

עם ה-CLI של shalom, לכל סוכן יש כתובת @shalomail.com משלו. הוא מקבל, קורא ושולח דואר אמיתי, מ-Shalom או מכל מקום, וכל פקודה מדברת JSON. המפתח הפרטי של התיבה נוצר במחשב של הסוכן ולא יוצא ממנו לעולם.

יצירת חשבון בחינםכבר יש לכם חשבון? פתחו את הסוכנים שלכם

מתחילים בשלוש פקודות

  1. התקינו את ה-CLI. נדרש Node.js 20 ומעלה.

    npm install -g shalomail

  2. חברו את הטרמינל לחשבון. הפקודה פותחת עמוד של Shalom, ואתם מאשרים בלחיצה אחת.

    shalom login

  3. צרו את התיבה של הסוכן. המפתח הפרטי שלה נוצר ונשמר במחשב הזה.

    shalom agents create yourname-bot

לקרוא, לענות ולשלוח

כל פקודה מקבלת --json, כדי שהסוכן יקרא את הפלט בלי לנחש. אפשר לקצר מזהים ל-8 התווים הראשונים.

shalom inbox --json
shalom read 3f9c2a1b --json
shalom reply 3f9c2a1b --text "התקבל, תודה."
shalom send --to ana@example.com --subject "דוח שבועי" \
  --text-file report.md --attach report.pdf

להגיב לכל דואר חדש

watch מחכה לדואר חדש ומריץ את התוכנית שלכם פעם אחת לכל הודעה, עם ההודעה כ-JSON בקלט הסטנדרטי.

shalom watch --exec "python agent.py" --mark-read

ה-JSON כולל id, from, to, cc, subject, date, text, html, messageId, verifiedSender ואת רשימת הקבצים המצורפים. הסביבה מקבלת גם SHALOM_MESSAGE_ID,‏ SHALOM_FROM ו-SHALOM_SUBJECT.

להריץ בשרת

ייצאו את התיבה למשתנה אחד והשתמשו בה בכל שרת, קונטיינר או CI. שמרו אותו כסוד: הוא מכיל את המפתח הפרטי.

shalom agents export yourname-bot@shalomail.com
SHALOM_AGENT_TOKEN=shalom_agent_... shalom inbox --json

אבטחה

  • המפתח הפרטי של כל תיבה נשאר במחשב של הסוכן. השרת שומר את הדואר חתום ולא יכול לקרוא אותו.
  • מפתח החשבון שלכם רק יוצר ומוחק תיבות סוכן. המפתח של כל תיבה רק קורא ושולח דרכה. אפשר להחליף או למחוק כל אחד מהם בכל רגע.
  • בין כתובות Shalom הדואר עובר חתום מקצה לקצה והשולח מאומת. לספקים אחרים הוא יוצא כדואר רגיל.

כל הפקודות

shalom login
מחבר את הטרמינל הזה לחשבון דרך הדפדפן.
shalom agents list
מציג את תיבות הסוכן שלכם ואת התוכנית.
shalom agents create <name>
יוצר את ‎<name>@shalomail.com, עם המפתח הפרטי במחשב הזה.
shalom agents delete <address>
מוחק את התיבה ואת כל הדואר שבה. צריך שהתיבה תהיה שמורה במחשב הזה; הכתובת נשארת שמורה עבורכם.
shalom agents rotate <address>
מנפיק מפתח API חדש לתיבה. הישן מפסיק לעבוד.
shalom agents export <address>
מדפיס את SHALOM_AGENT_TOKEN, כדי להריץ את התיבה במקום אחר.
shalom plan
מציג את התוכנית ואת מספר התיבות בשימוש.
shalom upgrade
פותח את עמוד התוכניות באפליקציה.
shalom inbox
מציג את ההודעות בתיקייה. ‎--unread מציג רק לא נקראות.
shalom read <id>
פותח הודעה. ‎--save-attachments שומר את הקבצים.
shalom send
שולח הודעה, עם הטקסט בפרמטר, בקובץ או בקלט הסטנדרטי, וקבצים מצורפים.
shalom reply <id>
עונה באותה שיחה. ‎--all עונה לכולם.
shalom move <id> --to <folder>
מעביר לדואר נכנס, לארכיון, לספאם או לאשפה.
shalom mark <id> --read
מסמן כנקרא או לא נקרא, עם כוכב או בלי.
shalom watch
מחכה לדואר חדש. ‎--exec מריץ פקודה לכל הודעה.

הריצו shalom --help לכל האפשרויות. כל הפקודות מקבלות --json, ו-‎--as <כתובת> בוחר את התיבה.
