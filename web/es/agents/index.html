Dale un buzón de correo a tus agentes de IA

Con el CLI shalom, cada agente tiene su propia dirección @shalomail.com. Recibe, lee y envía correo real, de Shalom o de cualquier lugar, y cada comando habla JSON. La clave privada del buzón nace en la máquina del agente y nunca sale de ahí.

Crear cuenta gratis¿Ya tienes cuenta? Abre tus agentes

Empieza con tres comandos

  1. Instala el CLI. Necesita Node.js 20 o más nuevo.

    npm install -g shalomail

  2. Conecta la terminal a tu cuenta. El comando abre una página de Shalom y confirmas con un clic.

    shalom login

  3. Crea el buzón de tu agente. Su clave privada se genera y se guarda en esta máquina.

    shalom agents create tunombre-bot

Leer, responder y enviar

Cada comando acepta --json, para que tu agente lea la salida sin adivinar. Los ids se pueden acortar a sus primeros 8 caracteres.

shalom inbox --json
shalom read 3f9c2a1b --json
shalom reply 3f9c2a1b --text "Recibido, gracias."
shalom send --to ana@example.com --subject "Informe semanal" \
  --text-file report.md --attach report.pdf

Reaccionar a cada correo nuevo

watch espera los correos nuevos y ejecuta tu programa una vez por mensaje, con el mensaje en JSON por la entrada estándar.

shalom watch --exec "python agent.py" --mark-read

El JSON trae id, from, to, cc, subject, date, text, html, messageId, verifiedSender y la lista de adjuntos. El entorno también recibe SHALOM_MESSAGE_ID, SHALOM_FROM y SHALOM_SUBJECT.

Ejecutarlo en un servidor

Exporta el buzón en una sola variable y úsalo en cualquier servidor, contenedor o CI. Guárdala como secreto: contiene la clave privada.

shalom agents export tunombre-bot@shalomail.com
SHALOM_AGENT_TOKEN=shalom_agent_... shalom inbox --json

Seguridad

  • La clave privada de cada buzón queda en la máquina del agente. El servidor guarda los correos sellados y no puede leerlos.
  • La clave de tu cuenta solo crea y borra buzones de agente. La clave de cada buzón solo lee y envía desde él. Puedes cambiar o borrar cualquiera en cualquier momento.
  • Entre direcciones Shalom, el correo viaja sellado de extremo a extremo y el remitente se verifica. A otros proveedores va como correo normal.

Todos los comandos

shalom login
Conecta esta terminal a tu cuenta desde el navegador.
shalom agents list
Lista tus buzones de agente y tu plan.
shalom agents create <name>
Crea <nombre>@shalomail.com, con la clave privada en esta máquina.
shalom agents delete <address>
Borra el buzón y todos sus correos. Necesita el buzón guardado en esta máquina; la dirección sigue reservada para ti.
shalom agents rotate <address>
Genera una clave de API nueva para el buzón. La anterior deja de funcionar.
shalom agents export <address>
Muestra SHALOM_AGENT_TOKEN, para ejecutar el buzón en otro lugar.
shalom plan
Muestra tu plan y cuántos buzones usas.
shalom upgrade
Abre la página de planes en la app.
shalom inbox
Lista los mensajes de una carpeta. --unread muestra solo los no leídos.
shalom read <id>
Abre un mensaje. --save-attachments guarda los archivos.
shalom send
Envía un mensaje, con el texto en un parámetro, un archivo o la entrada estándar, y adjuntos.
shalom reply <id>
Responde en la misma conversación. --all responde a todos.
shalom move <id> --to <folder>
Mueve a entrada, archivo, spam o papelera.
shalom mark <id> --read
Marca como leído o no leído, con o sin estrella.
shalom watch
Espera correos nuevos. --exec ejecuta un comando por cada mensaje.

Ejecuta shalom --help para ver todas las opciones. Todos los comandos aceptan --json, y --as <dirección> para elegir el buzón.

Shalom Mail (shalomail.com) es un servicio de correo cifrado que funciona en el navegador. Los correos guardados quedan cerrados con una clave que solo tu contraseña desbloquea, y entre cuentas Shalom todo va de extremo a extremo.
