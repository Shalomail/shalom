Gib deinen KI-Agenten ein Postfach

Mit der shalom-CLI bekommt jeder Agent seine eigene @shalomail.com-Adresse. Er empfängt, liest und sendet echte E-Mails, von Shalom oder von überall, und jeder Befehl spricht JSON. Der private Schlüssel des Postfachs entsteht auf dem Rechner des Agenten und verlässt ihn nie.

Kostenloses Konto erstellenSchon ein Konto? Öffne deine Agenten

In drei Befehlen starten

  1. Installiere die CLI. Sie braucht Node.js 20 oder neuer.

    npm install -g shalomail

  2. Verbinde das Terminal mit deinem Konto. Der Befehl öffnet eine Shalom-Seite, und du bestätigst mit einem Klick.

    shalom login

  3. Erstelle das Postfach für deinen Agenten. Sein privater Schlüssel wird auf diesem Rechner erzeugt und gespeichert.

    shalom agents create deinname-bot

Lesen, antworten und senden

Jeder Befehl versteht --json, damit dein Agent die Ausgabe ohne Raten liest. IDs lassen sich auf ihre ersten 8 Zeichen kürzen.

shalom inbox --json
shalom read 3f9c2a1b --json
shalom reply 3f9c2a1b --text "Erhalten, danke."
shalom send --to ana@example.com --subject "Wochenbericht" \
  --text-file report.md --attach report.pdf

Auf jede neue E-Mail reagieren

watch wartet auf neue E-Mails und startet dein Programm einmal pro Nachricht, mit der Nachricht als JSON auf der Standardeingabe.

shalom watch --exec "python agent.py" --mark-read

Das JSON enthält id, from, to, cc, subject, date, text, html, messageId, verifiedSender und die Liste der Anhänge. Die Umgebung bekommt außerdem SHALOM_MESSAGE_ID, SHALOM_FROM und SHALOM_SUBJECT.

Auf einem Server betreiben

Exportiere das Postfach als eine einzige Variable und nutze es auf jedem Server, Container oder CI. Bewahre sie als Geheimnis auf: Sie enthält den privaten Schlüssel.

shalom agents export deinname-bot@shalomail.com
SHALOM_AGENT_TOKEN=shalom_agent_... shalom inbox --json

Sicherheit

  • Der private Schlüssel jedes Postfachs bleibt auf dem Rechner des Agenten. Der Server speichert die E-Mails versiegelt und kann sie nicht lesen.
  • Der Schlüssel deines Kontos erstellt und löscht nur Agenten-Postfächer. Der Schlüssel jedes Postfachs liest und sendet nur über dieses. Du kannst jeden jederzeit erneuern oder löschen.
  • Zwischen Shalom-Adressen reist die E-Mail Ende-zu-Ende versiegelt, und der Absender wird geprüft. Zu anderen Anbietern geht sie als normale E-Mail.

Alle Befehle

shalom login
Verbindet dieses Terminal über den Browser mit deinem Konto.
shalom agents list
Listet deine Agenten-Postfächer und deinen Tarif auf.
shalom agents create <name>
Erstellt <name>@shalomail.com, mit dem privaten Schlüssel auf diesem Rechner.
shalom agents delete <address>
Löscht das Postfach und alle E-Mails darin. Das Postfach muss auf diesem Rechner gespeichert sein; die Adresse bleibt für dich reserviert.
shalom agents rotate <address>
Stellt einen neuen API-Schlüssel für das Postfach aus. Der alte gilt nicht mehr.
shalom agents export <address>
Gibt SHALOM_AGENT_TOKEN aus, um das Postfach woanders zu betreiben.
shalom plan
Zeigt deinen Tarif und wie viele Postfächer du nutzt.
shalom upgrade
Öffnet die Tarifseite in der App.
shalom inbox
Listet die Nachrichten eines Ordners. --unread zeigt nur ungelesene.
shalom read <id>
Öffnet eine Nachricht. --save-attachments speichert die Dateien.
shalom send
Sendet eine Nachricht, mit dem Text als Option, aus einer Datei oder der Standardeingabe, samt Anhängen.
shalom reply <id>
Antwortet in derselben Unterhaltung. --all antwortet allen.
shalom move <id> --to <folder>
Verschiebt in Posteingang, Archiv, Spam oder Papierkorb.
shalom mark <id> --read
Markiert als gelesen oder ungelesen, mit oder ohne Stern.
shalom watch
Wartet auf neue E-Mails. --exec startet für jede Nachricht einen Befehl.

Mit shalom --help siehst du alle Optionen. Alle Befehle verstehen --json, und --as <Adresse> wählt das Postfach.

Shalom Mail (shalomail.com) ist ein verschlüsselter E-Mail-Dienst, der im Browser läuft. Gespeicherte E-Mails sind mit einem Schlüssel verschlossen, den es nur auf deinem Gerät gibt, und zwischen Shalom-Konten ist alles Ende-zu-Ende verschlüsselt.
