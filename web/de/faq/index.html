Das Konto

Was ist Shalom Mail?

Shalom Mail ist ein verschlüsselter E-Mail-Dienst, der im Browser läuft, unter shalomail.com. Das Konto ist kostenlos, mit 1 GB und einer @shalomail.com-Adresse. Gespeicherte E-Mails sind mit einem Schlüssel verschlossen, den es nur auf deinem Gerät gibt, E-Mails zwischen Shalom-Konten sind Ende-zu-Ende verschlüsselt, und KI-Agenten können eigene Postfächer bekommen.

Ist Shalom Mail kostenlos?

Ja. Das E-Mail-Konto ist kostenlos, mit 1 GB Speicher und einer @shalomail.com-Adresse, und es gibt keine Werbung. Kostenpflichtige Pläne gibt es nur für alle, die mehr als 2 Postfächer für KI-Agenten brauchen.

Brauche ich eine Telefonnummer oder einen Ausweis für die Anmeldung?

Nein. Du wählst eine Adresse und ein Passwort, und Shalom fragt weder nach einer Telefonnummer noch nach einem Ausweis. Bevor dein erstes Postfach aufgeht, fragt es nach einer Wiederherstellungs-E-Mail bei einem anderen Anbieter: Darüber kommst du wieder in dein Konto, wenn du dein Passwort vergisst. Der Server bewahrt sie verschlossen auf und nutzt sie nur, um dir einen Link zu schicken.

Kann ich Leuten bei Gmail oder Outlook schreiben?

Ja. Eine Shalom-Adresse sendet an jeden Anbieter und empfängt von jedem, etwa Gmail, Outlook, iCloud oder Yahoo, und die Leute dort bekommen deine Nachrichten als normale E-Mail. Zwischen Shalom-Konten ist es Ende-zu-Ende verschlüsselt.

Gibt es eine App zum Installieren?

Nein. Shalom Mail läuft im Browser, auf Computer und Handy, es gibt also nichts zu installieren. Postfächer für KI-Agenten nutzt du mit dem shalom-CLI oder dem Node-SDK.

Kann ich mein Konto löschen?

Ja. Schreib an contato@shalomail.com, und das Konto wird gelöscht, mit seinen gespeicherten E-Mails und Kontodaten. Sicherungskopien der Infrastruktur können einige Tage brauchen, bis sie ablaufen.

Datenschutz und Verschlüsselung

Kann Shalom meine E-Mails lesen?

Deine gespeicherten E-Mails nicht. Jede Nachricht ist mit einem Schlüssel versiegelt, den es nur auf deinem Gerät gibt, und der Server bewahrt sie auf, ohne sie öffnen zu können. E-Mails von anderen Anbietern kann der Server in dem Moment lesen, in dem sie ankommen, bevor sie versiegelt werden, und E-Mails, die du an andere Anbieter schickst, gehen als normale E-Mail hinaus.

So funktioniert die Verschlüsselung

Ist Shalom Mail Ende-zu-Ende verschlüsselt?

Zwischen Shalom-Konten ja. Die Nachricht wird auf dem Gerät des Absenders versiegelt und öffnet sich nur auf dem des Empfängers, und selbst der Absender bleibt dem Server verborgen. Mit anderen Anbietern geht das nicht, weil normale E-Mails unverschlüsselt reisen. Deshalb versiegelt Shalom diese Nachrichten in dem Moment, in dem sie ankommen.

So funktioniert die Verschlüsselung

Was passiert, wenn ich mein Passwort vergesse?

Deine gespeicherten E-Mails lassen sich nicht wiederherstellen, denn nur dein Passwort öffnet deinen Schlüssel und Shalom hat keine Kopie davon. Mit deiner Wiederherstellungs-E-Mail kannst du ein neues Passwort festlegen und deine Adresse behalten, aber das Postfach beginnt leer.

Welche Verschlüsselung nutzt Shalom Mail?

X25519-Schlüssel mit HKDF-SHA256 und AES-256-GCM für jede gespeicherte Nachricht, Argon2id für das Passwort auf deinem Gerät, Ed25519-Zertifikate für den versiegelten Absender und RSA-Blindsignaturen für die anonyme Zustellung zwischen Shalom-Konten.

So funktioniert die Verschlüsselung

Ist der Code von Shalom Mail offen?

Er ist offen für Prüfungen: Jeder kann den Code auf GitHub lesen, ihn bauen und prüfen, dass es derselbe Code ist, der auf shalomail.com läuft. Open Source ist er nicht, denn die Lizenz erlaubt nicht, den Code in einem anderen Dienst wiederzuverwenden. Sicherheitsprobleme kannst du an security@shalomail.com melden.

Nutzt es PGP?

Nein. Shalom hat ein eigenes Format auf Basis von X25519, HKDF-SHA256 und AES-256-GCM und nutzt keine PGP-Schlüssel. E-Mails an andere Anbieter gehen als normale E-Mail hinaus.

Gibt es Werbung oder Tracking?

Nein. Es gibt keine Werbung und keine Werbe-, Analyse- oder Tracking-Cookies, und deine E-Mails werden nicht zum Training von irgendetwas genutzt. Bilder, die melden, wann du eine E-Mail geöffnet hast, werden blockiert, und gefälschte Absender werden bernsteinfarben markiert.

Gibt Shalom Daten an Behörden heraus?

Nur auf gültige gerichtliche Anordnung. Was der Server hat, steht in der Datenschutzerklärung. Der Inhalt gespeicherter E-Mails bleibt verschlüsselt, und Shalom hat den Schlüssel nicht.

E-Mail für KI-Agenten

Wie gebe ich einem KI-Agenten eine eigene E-Mail-Adresse?

Installiere das shalom-CLI mit npm install -g shalomail, verbinde es mit shalom login mit deinem Konto, bestätigt im Browser, und führe shalom agents create mit einem Namen aus. Der Agent bekommt name@shalomail.com und kann echte E-Mails lesen, beantworten und senden, mit Ausgabe in JSON.

Was kosten Postfächer für KI-Agenten?

2 sind bei jedem Konto kostenlos. Agents 5 kostet 4,99 US$ im Monat für bis zu 5, Agents 12 kostet 9,99 US$ im Monat für bis zu 12, und Unlimited kostet 49,90 US$ im Monat, ohne Begrenzung der Postfächer und mit bis zu 250 neuen Postfächern pro Tag. Die Pläne laufen monatlich, werden über Stripe abgerechnet und sind jederzeit kündbar.

Kann Shalom die E-Mails meiner Agenten lesen?

Ihre gespeicherten E-Mails nicht. Jedes Agenten-Postfach hat einen eigenen privaten Schlüssel, erzeugt auf dem Rechner, auf dem du das CLI oder das SDK nutzt, und der Server bewahrt seine E-Mails versiegelt auf. Der Schlüssel deines Kontos kann Agenten-Postfächer erstellen und löschen, aber nicht öffnen.

Gibt es eine API oder ein SDK?

Ja. Das Paket shalomail auf npm ist zugleich das CLI und ein Node-SDK, mit den Klassen Agent und Account, und es gibt eine HTTP-API. Die Verschlüsselung passiert immer auf deiner Seite.

Kann ein Agent selbst auf neue E-Mails reagieren?

Ja. shalom watch --exec startet dein Programm einmal für jede neue Nachricht, mit der Nachricht als JSON auf der Standardeingabe, und agent.watch() macht dasselbe im SDK. Webhooks gibt es noch nicht.

Können Agenten Leuten außerhalb von Shalom schreiben?

Ja, als normale E-Mail. An externe Adressen sendet jedes Agenten-Postfach in der ersten Woche an bis zu 20 Empfänger pro Tag und danach an bis zu 100 pro Tag. Zwischen Shalom-Adressen ist es Ende-zu-Ende verschlüsselt, und der Absender wird geprüft.
