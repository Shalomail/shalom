よくある質問

shalomail.com の暗号化メールサービス、Shalom Mail についての短くて率直な回答です。

アカウント

Shalom Mail とは何ですか？

Shalom Mail は、shalomail.com で提供している、ブラウザで使える暗号化メールサービスです。アカウントは無料で、1 GB と @shalomail.com のアドレスが付きます。保存されたメールはあなたの端末にしかない鍵でロックされ、Shalom アカウント同士のメールはエンドツーエンドで暗号化され、AI エージェントも専用のメールボックスを持てます。

Shalom Mail は無料ですか？

はい。メールアカウントは無料で、1 GB のストレージと @shalomail.com のアドレスが付き、広告もありません。有料プランは、AI エージェント用のメールボックスが 2 個より多く必要な人のためだけのものです。

登録に電話番号や身分証は必要ですか？

いいえ。アドレスとパスワードを選ぶだけで、Shalom は電話番号も身分証も求めません。最初のメールボックスを開く前に、ほかのサービスの復旧用メールの登録をお願いしています。パスワードを忘れたとき、アカウントに戻るための手段です。サーバーはそれをロックして保管し、リンクを送るときにだけ使います。

Gmail や Outlook の人にもメールを送れますか？

はい。Shalom のアドレスは、Gmail、Outlook、iCloud、Yahoo など、どのサービスとも送受信できます。相手には通常のメールとして届きます。Shalom アカウント同士なら、エンドツーエンドで暗号化されます。

インストールするアプリはありますか？

いいえ。Shalom Mail はパソコンでもスマートフォンでもブラウザで使えるので、インストールは不要です。AI エージェント用のメールボックスは、shalom CLI か Node SDK で使います。

Shalom Mail はどの言語に対応していますか？

15 の言語に対応しています：ポルトガル語、英語、スペイン語、フランス語、ドイツ語、イタリア語、ロシア語、ウクライナ語、トルコ語、ヘブライ語、アラビア語、ヒンディー語、中国語、日本語、韓国語。

アカウントは削除できますか？

できます。サイトかアプリの「設定」の「アカウントを削除」から行うと、保存したメール、エージェント用メールボックス、アカウントのデータが削除され、有料プランも解約されます。インフラのバックアップが期限切れになるまで数日かかることがあります。

プライバシーと暗号化

Shalom は私のメールを読めますか？

保存されたメールは読めません。各メッセージはあなたの端末にしかない鍵で封印され、サーバーはそれを開けないまま保管しています。ほかのサービスから届くメールは、届いた瞬間、封印される前であればサーバーが読めます。また、ほかのサービスへ送るメールは通常のメールとして送信されます。

暗号化のしくみ

Shalom Mail はエンドツーエンドで暗号化されていますか？

Shalom アカウント同士では、はい。メッセージは送信者の端末で封印され、受信者の端末でしか開かず、送信者が誰かもサーバーには隠されます。ほかのメールサービスとの間では、通常のメールが暗号化されずに届くため不可能です。そのため Shalom は、そうしたメールを届いた瞬間に封印します。

暗号化のしくみ

パスワードを忘れたらどうなりますか？

保存されたメールは復元できません。あなたの鍵を開けられるのはパスワードだけで、Shalom はそのコピーを持っていないからです。復旧用メールを使えば新しいパスワードを設定してアドレスを残せますが、メールボックスは空の状態から始まります。

Shalom Mail はどんな暗号を使っていますか？

保存されるメッセージごとに X25519 の鍵と HKDF-SHA256、AES-256-GCM、端末上のパスワードに Argon2id、封印された送信者に Ed25519 の証明書、Shalom アカウント間の匿名配信に RSA ブラインド署名を使っています。

暗号化のしくみ

Shalom Mail のコードは公開されていますか？

監査のために公開しています。誰でも GitHub でコードを読み、ビルドして、shalomail.com で動いているものと同じコードであることを確かめられます。ライセンスで他のサービスへの再利用を認めていないため、オープンソースではありません。セキュリティの問題は security@shalomail.com までご報告ください。

GitHub でコードを見る

PGP は使っていますか？

いいえ。Shalom は X25519、HKDF-SHA256、AES-256-GCM をもとにした独自のフォーマットを使っており、PGP の鍵は使いません。ほかのサービスへのメールは通常のメールとして送信されます。

広告やトラッキングはありますか？

ありません。広告も、広告・分析・トラッキング用の Cookie もなく、あなたのメールが何かの学習に使われることもありません。メールを開いたことを知らせる画像はブロックされ、なりすましの送信者は琥珀色で表示されます。

Shalom は当局にデータを渡しますか？

有効な裁判所の命令がある場合だけです。サーバーが持っている情報はプライバシーポリシーに記載しています。保存されたメールの内容は暗号化されたままで、Shalom は鍵を持っていません。

プライバシーポリシー

AI エージェント用のメール

AI エージェントに専用のメールアドレスを持たせるには？

npm install -g shalomail で shalom CLI をインストールし、shalom login でアカウントに接続してブラウザで確認したら、名前を付けて shalom agents create を実行します。エージェントは name@shalomail.com を受け取り、本物のメールを読んだり、返信したり、送信したりでき、出力は JSON です。

AI エージェントのためのメール

AI エージェント用のメールボックスの料金は？

どのアカウントでも 2 個までは無料です。Agents 5 は最大 5 個で月額 4.99 ドル、Agents 12 は最大 12 個で月額 9.99 ドル、Unlimited はメールボックス数の上限なし、1 日 250 個まで新規作成できて月額 49.90 ドルです。プランは月額制で、Stripe で請求され、いつでも解約できます。

Shalom はエージェントのメールを読めますか？

保存されたメールは読めません。エージェント用のメールボックスには、CLI や SDK を動かすマシン上で作られた専用の秘密鍵があり、サーバーはそのメールを封印したまま保管しています。アカウントのキーはエージェント用メールボックスの作成と削除ができますが、開くことはできません。

API や SDK はありますか？

はい。npm の shalomail パッケージは CLI であると同時に、Agent クラスと Account クラスを備えた Node SDK でもあります。HTTP API もあります。暗号化は常にあなたの側で行われます。

Node SDK と HTTP API のリファレンス（英語）

エージェントが新しいメールに自動で反応できますか？

はい。shalom watch --exec は新しいメッセージごとにあなたのプログラムを 1 回実行し、メッセージを JSON として標準入力に渡します。SDK では agent.watch() が同じことをします。webhook はまだありません。

エージェントは Shalom 以外の人にメールを送れますか？

はい、通常のメールとして送れます。外部アドレスへは、各エージェント用メールボックスは最初の 1 週間は 1 日 20 人まで、その後は 1 日 100 人まで送信できます。Shalom のアドレス同士ではエンドツーエンドで暗号化され、送信者も確認されます。

無料でアカウントを作成暗号化のしくみ

Shalom Mail（shalomail.com）は、ブラウザで使える暗号化メールサービスです。保存されたメールはあなたの端末にしかない鍵でロックされ、Shalom アカウント同士のメールはエンドツーエンドで暗号化されます。
