AI エージェントにメールボックスを

shalom CLI を使えば、エージェントごとに専用の @shalomail.com アドレスが持てます。Shalom からでもどこからでも本物のメールを受信・閲覧・送信でき、すべてのコマンドが JSON に対応しています。メールボックスの秘密鍵はエージェントのマシンで生成され、外に出ることはありません。

無料でアカウントを作成アカウントをお持ちですか？エージェントを開く

3 つのコマンドで始める

  1. CLI をインストールします。Node.js 20 以降が必要です。

    npm install -g shalomail

  2. ターミナルをアカウントに接続します。コマンドが Shalom のページを開くので、クリックひとつで確認します。

    shalom login

  3. エージェントのメールボックスを作成します。秘密鍵はこのマシンで生成・保存されます。

    shalom agents create yourname-bot

読む、返信する、送る

すべてのコマンドが --json に対応しているので、エージェントは推測せずに出力を読めます。ID は先頭 8 文字に短縮できます。

shalom inbox --json
shalom read 3f9c2a1b --json
shalom reply 3f9c2a1b --text "受け取りました。ありがとうございます。"
shalom send --to ana@example.com --subject "週次レポート" \
  --text-file report.md --attach report.pdf

新着メールごとに反応する

watch は新着メールを待ち、メールごとにプログラムを 1 回実行します。メールは JSON として標準入力に渡されます。

shalom watch --exec "python agent.py" --mark-read

JSON には id, from, to, cc, subject, date, text, html, messageId, verifiedSender と添付ファイルの一覧が含まれます。環境変数として SHALOM_MESSAGE_ID、SHALOM_FROM、SHALOM_SUBJECT も渡されます。

サーバーで動かす

メールボックスを 1 つの変数としてエクスポートすれば、どのサーバー、コンテナ、CI でも使えます。秘密鍵を含むので、シークレットとして保管してください。

shalom agents export yourname-bot@shalomail.com
SHALOM_AGENT_TOKEN=shalom_agent_... shalom inbox --json

セキュリティ

  • 各メールボックスの秘密鍵はエージェントのマシンに残ります。サーバーはメールを封をしたまま保存し、読むことはできません。
  • アカウントのキーができるのは、エージェント用メールボックスの作成と削除だけです。各メールボックスのキーは、そのメールボックスでの閲覧と送信しかできません。どのキーもいつでも更新・削除できます。
  • Shalom のアドレス同士では、メールはエンドツーエンドで封をされて届き、送信者も確認されます。ほかのメールサービスへは通常のメールとして送られます。

AI エージェントのページまたは shalom upgrade で購読できます。外部アドレスへは、各メールボックスは最初の 1 週間は 1 日 20 人まで、その後は 1 日 100 人まで送信できます。

すべてのコマンド

shalom login
ブラウザでこのターミナルをアカウントに接続します。
shalom agents list
エージェント用メールボックスとプランを一覧表示します。
shalom agents create <name>
<name>@shalomail.com を作成します。秘密鍵はこのマシンに保存されます。
shalom agents delete <address>
メールボックスとすべてのメールを削除します。このマシンにメールボックスが保存されている必要があります。アドレスはあなたのために確保されます。
shalom agents rotate <address>
メールボックスの新しい API キーを発行します。古いキーは使えなくなります。
shalom agents export <address>
別の場所で動かすための SHALOM_AGENT_TOKEN を表示します。
shalom plan
プランと使用中のメールボックス数を表示します。
shalom upgrade
アプリのプランページを開きます。
shalom inbox
フォルダ内のメールを一覧表示します。--unread で未読のみ表示します。
shalom read <id>
メールを開きます。--save-attachments で添付ファイルを保存します。
shalom send
本文を引数、ファイル、標準入力のいずれかで渡し、添付ファイル付きでメールを送ります。
shalom reply <id>
同じスレッドで返信します。--all で全員に返信します。
shalom move <id> --to <folder>
受信トレイ、アーカイブ、迷惑メール、ゴミ箱に移動します。
shalom mark <id> --read
既読・未読、スターの有無を設定します。
shalom watch
新着メールを待ちます。--exec でメールごとにコマンドを実行します。

shalom --help ですべてのオプションを確認できます。すべてのコマンドが --json に対応し、--as <アドレス> でメールボックスを選べます。

Shalom Mail（shalomail.com）は、ブラウザで使える暗号化メールサービスです。保存されたメールはあなたの端末にしかない鍵でロックされ、Shalom アカウント同士のメールはエンドツーエンドで暗号化されます。
