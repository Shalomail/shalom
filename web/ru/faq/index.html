Вопросы и ответы

Короткие и прямые ответы о Shalom Mail, сервисе зашифрованной почты на shalomail.com.

Аккаунт

Что такое Shalom Mail?

Shalom Mail является сервисом зашифрованной почты, который работает в браузере, на shalomail.com. Аккаунт бесплатный, с 1 ГБ и адресом @shalomail.com. Сохранённые письма заперты ключом, который есть только на вашем устройстве, письма между аккаунтами Shalom идут со сквозным шифрованием, а у ИИ-агентов могут быть собственные ящики.

Shalom Mail бесплатный?

Да. Почтовый аккаунт бесплатный, с 1 ГБ места и адресом @shalomail.com, и в нём нет рекламы. Платные тарифы есть только для тех, кому нужно больше 2 ящиков для ИИ-агентов.

Нужны ли номер телефона или документы для регистрации?

Нет. Вы выбираете адрес и пароль, а Shalom не просит ни номер телефона, ни документы. Перед открытием первого ящика он просит резервный адрес в другом сервисе: через него вы вернётесь в аккаунт, если забудете пароль. Сервер хранит его запертым и использует только для того, чтобы отправить вам ссылку.

Можно ли писать тем, кто пользуется Gmail или Outlook?

Да. Адрес Shalom отправляет и получает письма с любым провайдером, например Gmail, Outlook, iCloud или Yahoo, и там ваши письма приходят как обычная почта. Между аккаунтами Shalom письма идут со сквозным шифрованием.

Нужно ли устанавливать приложение?

Нет. Shalom Mail работает в браузере, на компьютере и на телефоне, так что устанавливать ничего не нужно. Ящиками для ИИ-агентов пользуются через CLI shalom или Node SDK.

На каких языках доступен Shalom Mail?

Языков 15: португальский, английский, испанский, французский, немецкий, итальянский, русский, украинский, турецкий, иврит, арабский, хинди, китайский, японский и корейский.

Можно ли удалить аккаунт?

Да. Напишите на contato@shalomail.com, и аккаунт будет удалён вместе с сохранёнными письмами и данными аккаунта. Резервные копии инфраструктуры могут удаляться ещё несколько дней.

Конфиденциальность и шифрование

Может ли Shalom читать мою почту?

Сохранённые письма не может. Каждое письмо запечатано ключом, который есть только на вашем устройстве, и сервер хранит его, не имея возможности открыть. Письма из других сервисов сервер может прочитать в момент получения, до того как запечатает, а письма, которые вы отправляете в другие сервисы, уходят как обычная почта.

Как устроено шифрование

Есть ли в Shalom Mail сквозное шифрование?

Между аккаунтами Shalom есть. Письмо запечатывается на устройстве отправителя и открывается только на устройстве получателя, и даже отправитель скрыт от сервера. С другими провайдерами это невозможно, потому что обычная почта идёт незашифрованной, поэтому Shalom запечатывает такие письма сразу при получении.

Как устроено шифрование

Что будет, если я забуду пароль?

Сохранённые письма восстановить нельзя, потому что ваш ключ открывает только ваш пароль, а копии у Shalom нет. С резервным адресом можно задать новый пароль и сохранить адрес, но ящик будет пустым.

Какое шифрование использует Shalom Mail?

Ключи X25519 с HKDF-SHA256 и AES-256-GCM для каждого сохранённого письма, Argon2id для пароля на вашем устройстве, сертификаты Ed25519 для запечатанного отправителя и слепые подписи RSA для анонимной доставки между аккаунтами Shalom.

Как устроено шифрование

Открыт ли код Shalom Mail?

Он открыт для аудита: любой может прочитать код на GitHub, собрать его и убедиться, что это тот же код, который работает на shalomail.com. Это не open source: лицензия не разрешает использовать код в другом сервисе. О проблемах безопасности можно сообщить на security@shalomail.com.

Код на GitHub

Используется ли PGP?

Нет. У Shalom собственный формат на основе X25519, HKDF-SHA256 и AES-256-GCM, и ключи PGP не используются. Письма в другие сервисы уходят как обычная почта.

Есть ли реклама или слежка?

Нет. Нет ни рекламы, ни рекламных, аналитических или отслеживающих cookie, и ваши письма ни на чём не обучают. Картинки, которые сообщают, когда вы открыли письмо, блокируются, а поддельные отправители подсвечиваются янтарным.

Передаёт ли Shalom данные властям?

Только по действительному решению суда. Что есть у сервера, перечислено в политике конфиденциальности. Содержимое сохранённых писем остаётся зашифрованным, а ключа у Shalom нет.

Почта для ИИ-агентов

Как дать ИИ-агенту собственный почтовый адрес?

Установите CLI shalom командой npm install -g shalomail, подключите его к аккаунту командой shalom login с подтверждением в браузере и выполните shalom agents create с именем. Агент получит имя@shalomail.com и сможет читать, отвечать и отправлять настоящие письма, с выводом в JSON.

Почта для ИИ-агентов

Сколько стоят ящики для ИИ-агентов?

2 ящика бесплатны в любом аккаунте. Agents 5 стоит $4,99 в месяц (до 5 ящиков), Agents 12 стоит $9,99 в месяц (до 12), а Unlimited стоит $49,90 в месяц, без ограничения числа ящиков и до 250 новых ящиков в день. Тарифы помесячные, оплата идёт через Stripe, отменить можно в любой момент.

Может ли Shalom читать почту моих агентов?

Сохранённые письма не может. У каждого ящика агента свой закрытый ключ, созданный на машине, где вы запускаете CLI или SDK, и сервер хранит его письма запечатанными. Ключ вашего аккаунта может создавать и удалять ящики агентов, но не может их открыть.

Есть ли API или SDK?

Да. Пакет shalomail в npm одновременно является CLI и Node SDK с классами Agent и Account, а также есть HTTP API. Шифрование всегда происходит на вашей стороне.

Справочник по Node SDK и HTTP API (на английском)

Может ли агент сам реагировать на новые письма?

Да. shalom watch --exec запускает вашу программу по разу на каждое новое письмо и передаёт письмо в JSON на стандартный ввод, а agent.watch() делает то же в SDK. Вебхуков пока нет.

Могут ли агенты писать тем, кто не в Shalom?

Да, как обычная почта. На внешние адреса каждый ящик агента отправляет письма до 20 получателям в день в первую неделю и до 100 в день после этого. Между адресами Shalom письма идут со сквозным шифрованием, а отправитель проверяется.
