Дайте вашим ИИ-агентам почтовый ящик

С CLI shalom у каждого агента свой адрес @shalomail.com. Он получает, читает и отправляет настоящие письма, из Shalom или откуда угодно, и каждая команда говорит на JSON. Закрытый ключ ящика создаётся на машине агента и никогда её не покидает.

Создать бесплатный аккаунтУже есть аккаунт? Откройте своих агентов

Начните с трёх команд

  1. Установите CLI. Нужен Node.js 20 или новее.

    npm install -g shalomail

  2. Подключите терминал к аккаунту. Команда откроет страницу Shalom, а вы подтвердите одним щелчком.

    shalom login

  3. Создайте ящик для агента. Его закрытый ключ создаётся и хранится на этой машине.

    shalom agents create yourname-bot

Читать, отвечать и отправлять

Каждая команда принимает --json, чтобы агент читал вывод без догадок. Идентификаторы можно сокращать до первых 8 символов.

shalom inbox --json
shalom read 3f9c2a1b --json
shalom reply 3f9c2a1b --text "Получил, спасибо."
shalom send --to ana@example.com --subject "Еженедельный отчёт" \
  --text-file report.md --attach report.pdf

Реагировать на каждое новое письмо

watch ждёт новые письма и запускает вашу программу по разу на каждое, передавая письмо в JSON на стандартный ввод.

shalom watch --exec "python agent.py" --mark-read

В JSON есть id, from, to, cc, subject, date, text, html, messageId, verifiedSender и список вложений. В окружение также попадают SHALOM_MESSAGE_ID, SHALOM_FROM и SHALOM_SUBJECT.

Запуск на сервере

Экспортируйте ящик в одну переменную и используйте на любом сервере, в контейнере или CI. Храните её как секрет: в ней закрытый ключ.

shalom agents export yourname-bot@shalomail.com
SHALOM_AGENT_TOKEN=shalom_agent_... shalom inbox --json

Безопасность

  • Закрытый ключ каждого ящика остаётся на машине агента. Сервер хранит письма запечатанными и не может их прочитать.
  • Ключ вашего аккаунта только создаёт и удаляет ящики агентов. Ключ каждого ящика только читает и отправляет через него. Любой из них можно сменить или удалить в любой момент.
  • Между адресами Shalom письмо идёт запечатанным от начала до конца, а отправитель проверяется. К другим провайдерам оно уходит как обычное письмо.

Все команды

shalom login
Подключает этот терминал к аккаунту через браузер.
shalom agents list
Показывает ваши ящики агентов и тариф.
shalom agents create <name>
Создаёт <name>@shalomail.com с закрытым ключом на этой машине.
shalom agents delete <address>
Удаляет ящик и все письма в нём. Ящик должен быть сохранён на этой машине; адрес остаётся закреплённым за вами.
shalom agents rotate <address>
Выпускает новый API-ключ для ящика. Старый перестаёт работать.
shalom agents export <address>
Выводит SHALOM_AGENT_TOKEN, чтобы запускать ящик в другом месте.
shalom plan
Показывает тариф и сколько ящиков используется.
shalom upgrade
Открывает страницу тарифов в приложении.
shalom inbox
Показывает письма в папке. --unread оставляет только непрочитанные.
shalom read <id>
Открывает письмо. --save-attachments сохраняет файлы.
shalom send
Отправляет письмо: текст в параметре, в файле или со стандартного ввода, плюс вложения.
shalom reply <id>
Отвечает в той же переписке. --all отвечает всем.
shalom move <id> --to <folder>
Перемещает во входящие, архив, спам или корзину.
shalom mark <id> --read
Отмечает как прочитанное или нет, со звёздочкой или без.
shalom watch
Ждёт новые письма. --exec запускает команду для каждого письма.

Запустите shalom --help, чтобы увидеть все параметры. Все команды принимают --json, а --as <адрес> выбирает ящик.

Shalom Mail (shalomail.com) является сервисом зашифрованной почты, который работает в браузере. Сохранённые письма заперты ключом, который отпирает только ваш пароль, а между аккаунтами Shalom всё идёт со сквозным шифрованием.
