Give your AI agents a mailbox

With the shalom CLI, each agent gets its own @shalomail.com address. It receives, reads and sends real email, from Shalom or from anywhere, and every command speaks JSON. The mailbox's private key is created on the agent's machine and never leaves it.

Start in three commands

  1. Install the CLI. It needs Node.js 20 or newer.

    npm install -g shalomail

  2. Connect the terminal to your account. The command opens a Shalom page, and you confirm with one click.

    shalom login

  3. Create your agent's mailbox. Its private key is generated and stored on this machine.

    shalom agents create yourname-bot

Read, reply and send

Every command accepts --json, so your agent reads the output without guessing. Ids can be shortened to their first 8 characters.

shalom inbox --json
shalom read 3f9c2a1b --json
shalom reply 3f9c2a1b --text "Got it, thanks."
shalom send --to ana@example.com --subject "Weekly report" \
  --text-file report.md --attach report.pdf

React to every new email

watch waits for new mail and runs your program once per message, with the message as JSON on standard input.

shalom watch --exec "python agent.py" --mark-read

The JSON has id, from, to, cc, subject, date, text, html, messageId, verifiedSender and the list of attachments. The environment also gets SHALOM_MESSAGE_ID, SHALOM_FROM and SHALOM_SUBJECT.

Run it on a server

Export the mailbox as a single variable and use it on any server, container or CI. Store it as a secret: it contains the private key.

shalom agents export yourname-bot@shalomail.com
SHALOM_AGENT_TOKEN=shalom_agent_... shalom inbox --json

Security

  • Each mailbox's private key stays on the agent's machine. The server stores the mail sealed and cannot read it.
  • Your account key only creates and deletes agent mailboxes. Each mailbox's key only reads and sends through it. You can rotate or delete any of them at any time.
  • Between Shalom addresses, mail travels sealed end to end and the sender is verified. To other providers it goes as regular email.

All commands

shalom login
Connects this terminal to your account through the browser.
shalom agents list
Lists your agent mailboxes and your plan.
shalom agents create <name>
Creates <name>@shalomail.com, with the private key on this machine.
shalom agents delete <address>
Deletes the mailbox and all its mail. Needs the mailbox saved on this machine; the address stays reserved for you.
shalom agents rotate <address>
Issues a new API key for the mailbox. The old one stops working.
shalom agents export <address>
Prints SHALOM_AGENT_TOKEN, to run the mailbox somewhere else.
shalom plan
Shows your plan and how many mailboxes you use.
shalom upgrade
Opens the plans page in the app.
shalom inbox
Lists the messages in a folder. --unread shows only unread ones.
shalom read <id>
Opens a message. --save-attachments saves the files.
shalom send
Sends a message, with the text in a flag, a file or standard input, plus attachments.
shalom reply <id>
Replies in the same thread. --all replies to everyone.
shalom move <id> --to <folder>
Moves to inbox, archive, spam or trash.
shalom mark <id> --read
Marks as read or unread, starred or not.
shalom watch
Waits for new mail. --exec runs a command for each message.

Run shalom --help for every option. All commands accept --json, and --as <address> to pick the mailbox.

Shalom Mail (shalomail.com) is an encrypted email service that works in the browser. Stored email is locked with a key that only exists on your device, and mail between Shalom accounts is end to end.
