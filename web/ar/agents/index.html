امنح وكلاء الذكاء الاصطناعي صندوق بريد

مع واجهة shalom لسطر الأوامر، يحصل كل وكيل على عنوان ‎@shalomail.com خاص به. يستقبل البريد الحقيقي ويقرؤه ويرسله، من Shalom أو من أي مكان، وكل أمر يتحدث JSON. يُنشأ المفتاح الخاص للصندوق على جهاز الوكيل ولا يغادره أبدًا.

أنشئ حسابًا مجانيًالديك حساب؟ افتح وكلاءك

ابدأ بثلاثة أوامر

  1. ثبّت واجهة سطر الأوامر. تحتاج Node.js 20 أو أحدث.

    npm install -g shalomail

  2. اربط الطرفية بحسابك. يفتح الأمر صفحة من Shalom، وتؤكد بنقرة واحدة.

    shalom login

  3. أنشئ صندوق وكيلك. يُولَّد مفتاحه الخاص ويُحفظ على هذا الجهاز.

    shalom agents create yourname-bot

القراءة والرد والإرسال

كل أمر يقبل ‎--json، ليقرأ وكيلك المخرجات دون تخمين. يمكن اختصار المعرّفات إلى أول 8 أحرف.

shalom inbox --json
shalom read 3f9c2a1b --json
shalom reply 3f9c2a1b --text "وصل، شكرًا."
shalom send --to ana@example.com --subject "تقرير أسبوعي" \
  --text-file report.md --attach report.pdf

التفاعل مع كل بريد جديد

ينتظر watch البريد الجديد ويشغّل برنامجك مرة لكل رسالة، مع الرسالة بصيغة JSON على الإدخال القياسي.

shalom watch --exec "python agent.py" --mark-read

يحتوي JSON على id, from, to, cc, subject, date, text, html, messageId, verifiedSender وقائمة المرفقات. وتتلقى البيئة أيضًا SHALOM_MESSAGE_ID و SHALOM_FROM و SHALOM_SUBJECT.

التشغيل على خادم

صدّر الصندوق في متغير واحد واستخدمه على أي خادم أو حاوية أو CI. احفظه كسرّ: فهو يحتوي على المفتاح الخاص.

shalom agents export yourname-bot@shalomail.com
SHALOM_AGENT_TOKEN=shalom_agent_... shalom inbox --json

الأمان

  • يبقى المفتاح الخاص لكل صندوق على جهاز الوكيل. يحفظ الخادم البريد مختومًا ولا يستطيع قراءته.
  • مفتاح حسابك ينشئ صناديق الوكلاء ويحذفها فقط. ومفتاح كل صندوق يقرأ ويرسل عبره فقط. يمكنك تجديد أي منها أو حذفه في أي وقت.
  • بين عناوين Shalom يسافر البريد مختومًا من الطرف إلى الطرف ويُتحقق من المرسل. وإلى المزوّدين الآخرين يُرسل كبريد عادي.

كل الأوامر

shalom login
يربط هذه الطرفية بحسابك عبر المتصفح.
shalom agents list
يعرض صناديق وكلائك وخطتك.
shalom agents create <name>
ينشئ ‎<name>@shalomail.com، مع المفتاح الخاص على هذا الجهاز.
shalom agents delete <address>
يحذف الصندوق وكل بريده. يجب أن يكون الصندوق محفوظًا على هذا الجهاز؛ ويبقى العنوان محجوزًا لك.
shalom agents rotate <address>
يُصدر مفتاح API جديدًا للصندوق. ويتوقف القديم عن العمل.
shalom agents export <address>
يطبع SHALOM_AGENT_TOKEN لتشغيل الصندوق في مكان آخر.
shalom plan
يعرض خطتك وعدد الصناديق المستخدمة.
shalom upgrade
يفتح صفحة الخطط في التطبيق.
shalom inbox
يعرض رسائل مجلد. ‎--unread يعرض غير المقروءة فقط.
shalom read <id>
يفتح رسالة. ‎--save-attachments يحفظ الملفات.
shalom send
يرسل رسالة، والنص في خيار أو ملف أو الإدخال القياسي، مع مرفقات.
shalom reply <id>
يرد في المحادثة نفسها. ‎--all يرد على الجميع.
shalom move <id> --to <folder>
ينقل إلى الوارد أو الأرشيف أو البريد المزعج أو المهملات.
shalom mark <id> --read
يعلّم كمقروء أو غير مقروء، بنجمة أو بدونها.
shalom watch
ينتظر بريدًا جديدًا. ‎--exec يشغّل أمرًا لكل رسالة.

شغّل shalom --help لرؤية كل الخيارات. كل الأوامر تقبل ‎--json، و‎--as <العنوان> لاختيار الصندوق.

Shalom Mail (shalomail.com) خدمة بريد إلكتروني مشفّر تعمل في المتصفح. الرسائل المحفوظة مقفلة بمفتاح لا يوجد إلا على جهازك، وبين حسابات Shalom يكون كل شيء مشفّرًا من طرف إلى طرف.
