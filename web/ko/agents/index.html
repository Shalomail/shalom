AI 에이전트에게 메일함을 주세요

shalom CLI를 쓰면 에이전트마다 자기만의 @shalomail.com 주소가 생깁니다. Shalom에서든 어디서든 실제 메일을 받고, 읽고, 보내며, 모든 명령이 JSON을 지원합니다. 메일함의 개인 키는 에이전트의 컴퓨터에서 만들어지고 절대 밖으로 나가지 않습니다.

무료 계정 만들기이미 계정이 있나요? 내 에이전트 열기

명령 세 개로 시작하기

  1. CLI를 설치하세요. Node.js 20 이상이 필요합니다.

    npm install -g shalomail

  2. 터미널을 계정에 연결하세요. 명령이 Shalom 페이지를 열고, 클릭 한 번으로 확인하면 됩니다.

    shalom login

  3. 에이전트의 메일함을 만드세요. 개인 키는 이 컴퓨터에서 만들어지고 저장됩니다.

    shalom agents create yourname-bot

읽기, 답장, 보내기

모든 명령이 --json을 지원하므로 에이전트가 추측 없이 출력을 읽습니다. ID는 앞 8자로 줄여 쓸 수 있습니다.

shalom inbox --json
shalom read 3f9c2a1b --json
shalom reply 3f9c2a1b --text "잘 받았습니다. 감사합니다."
shalom send --to ana@example.com --subject "주간 보고서" \
  --text-file report.md --attach report.pdf

새 메일마다 반응하기

watch는 새 메일을 기다렸다가 메일마다 프로그램을 한 번씩 실행하고, 메일을 JSON으로 표준 입력에 넘깁니다.

shalom watch --exec "python agent.py" --mark-read

JSON에는 id, from, to, cc, subject, date, text, html, messageId, verifiedSender와 첨부 파일 목록이 들어 있습니다. 환경 변수로 SHALOM_MESSAGE_ID, SHALOM_FROM, SHALOM_SUBJECT도 전달됩니다.

서버에서 실행하기

메일함을 변수 하나로 내보내면 어떤 서버, 컨테이너, CI에서도 쓸 수 있습니다. 개인 키가 들어 있으니 비밀로 보관하세요.

shalom agents export yourname-bot@shalomail.com
SHALOM_AGENT_TOKEN=shalom_agent_... shalom inbox --json

보안

  • 각 메일함의 개인 키는 에이전트의 컴퓨터에 남습니다. 서버는 메일을 봉인된 채로 보관하며 읽을 수 없습니다.
  • 계정 키는 에이전트 메일함을 만들고 지우는 일만 합니다. 각 메일함의 키는 그 메일함으로 읽고 보내는 일만 합니다. 어떤 키든 언제든 교체하거나 삭제할 수 있습니다.
  • Shalom 주소끼리는 메일이 종단 간 봉인되어 전달되고 보낸 사람이 확인됩니다. 다른 메일 서비스로는 일반 메일로 보내집니다.

암호화는 이렇게 작동합니다

요금제

  • 무료에이전트 메일함 2개
  • Agents 5메일함 최대 5개, 월 4.99달러
  • Agents 12메일함 최대 12개, 월 9.99달러
  • Unlimited메일함 무제한, 하루 최대 250개 새로, 월 49.90달러

AI 에이전트 페이지에서 또는 shalom upgrade로 구독하세요. 외부 주소로는 각 메일함이 첫 주에는 하루 최대 20명, 그 뒤로는 하루 최대 100명에게 보낼 수 있습니다.

모든 명령

shalom login
브라우저로 이 터미널을 계정에 연결합니다.
shalom agents list
에이전트 메일함과 요금제를 보여 줍니다.
shalom agents create <name>
<name>@shalomail.com을 만들고 개인 키를 이 컴퓨터에 둡니다.
shalom agents delete <address>
메일함과 그 안의 모든 메일을 삭제합니다. 이 컴퓨터에 메일함이 저장되어 있어야 하며, 주소는 계속 회원님을 위해 예약됩니다.
shalom agents rotate <address>
메일함의 새 API 키를 발급합니다. 이전 키는 더 이상 작동하지 않습니다.
shalom agents export <address>
다른 곳에서 메일함을 실행할 수 있게 SHALOM_AGENT_TOKEN을 출력합니다.
shalom plan
요금제와 사용 중인 메일함 수를 보여 줍니다.
shalom upgrade
앱의 요금제 페이지를 엽니다.
shalom inbox
폴더의 메일을 보여 줍니다. --unread는 읽지 않은 메일만 보여 줍니다.
shalom read <id>
메일을 엽니다. --save-attachments는 파일을 저장합니다.
shalom send
본문을 인자, 파일, 표준 입력 중 하나로 받아 첨부 파일과 함께 메일을 보냅니다.
shalom reply <id>
같은 대화에서 답장합니다. --all은 모두에게 답장합니다.
shalom move <id> --to <folder>
받은편지함, 보관함, 스팸, 휴지통으로 옮깁니다.
shalom mark <id> --read
읽음 또는 안 읽음, 별표 여부를 표시합니다.
shalom watch
새 메일을 기다립니다. --exec는 메일마다 명령을 실행합니다.

모든 옵션은 shalom --help로 확인하세요. 모든 명령이 --json을 지원하며, --as <주소>로 메일함을 고릅니다.

Shalom Mail(shalomail.com)은 브라우저에서 쓰는 암호화 이메일 서비스입니다. 저장된 이메일은 회원님의 기기에만 있는 키로 잠기고, Shalom 계정끼리는 모든 메일이 종단 간 암호화됩니다.
