Дайте своїм ШІ-агентам поштову скриньку

З CLI shalom кожен агент має власну адресу @shalomail.com. Він отримує, читає й надсилає справжні листи, із Shalom чи звідки завгодно, і кожна команда говорить JSON. Приватний ключ скриньки створюється на машині агента й ніколи її не залишає.

Створити безкоштовний акаунтУже маєте акаунт? Відкрийте своїх агентів

Почніть із трьох команд

  1. Встановіть CLI. Потрібен Node.js 20 або новіший.

    npm install -g shalomail

  2. Підключіть термінал до акаунта. Команда відкриє сторінку Shalom, а ви підтвердите одним клацанням.

    shalom login

  3. Створіть скриньку для агента. Її приватний ключ створюється й зберігається на цій машині.

    shalom agents create yourname-bot

Читати, відповідати й надсилати

Кожна команда приймає --json, щоб агент читав вивід без здогадів. Ідентифікатори можна скорочувати до перших 8 символів.

shalom inbox --json
shalom read 3f9c2a1b --json
shalom reply 3f9c2a1b --text "Отримав, дякую."
shalom send --to ana@example.com --subject "Щотижневий звіт" \
  --text-file report.md --attach report.pdf

Реагувати на кожен новий лист

watch чекає нові листи й запускає вашу програму раз на кожен, передаючи лист у JSON на стандартний вхід.

shalom watch --exec "python agent.py" --mark-read

У JSON є id, from, to, cc, subject, date, text, html, messageId, verifiedSender і список вкладень. До оточення також потрапляють SHALOM_MESSAGE_ID, SHALOM_FROM і SHALOM_SUBJECT.

Запуск на сервері

Експортуйте скриньку в одну змінну й використовуйте на будь-якому сервері, у контейнері чи CI. Зберігайте її як секрет: у ній приватний ключ.

shalom agents export yourname-bot@shalomail.com
SHALOM_AGENT_TOKEN=shalom_agent_... shalom inbox --json

Безпека

  • Приватний ключ кожної скриньки лишається на машині агента. Сервер зберігає листи запечатаними й не може їх прочитати.
  • Ключ вашого акаунта лише створює й видаляє скриньки агентів. Ключ кожної скриньки лише читає й надсилає через неї. Будь-який із них можна змінити чи видалити будь-коли.
  • Між адресами Shalom лист іде наскрізно запечатаним, а відправника перевірено. До інших провайдерів він іде як звичайний лист.

Усі команди

shalom login
Підключає цей термінал до акаунта через браузер.
shalom agents list
Показує ваші скриньки агентів і тариф.
shalom agents create <name>
Створює <name>@shalomail.com з приватним ключем на цій машині.
shalom agents delete <address>
Видаляє скриньку й усі листи в ній. Скринька має бути збережена на цій машині; адреса лишається закріпленою за вами.
shalom agents rotate <address>
Видає новий API-ключ для скриньки. Старий перестає працювати.
shalom agents export <address>
Виводить SHALOM_AGENT_TOKEN, щоб запускати скриньку деінде.
shalom plan
Показує тариф і скільки скриньок використано.
shalom upgrade
Відкриває сторінку тарифів у застосунку.
shalom inbox
Показує листи в теці. --unread лишає тільки непрочитані.
shalom read <id>
Відкриває лист. --save-attachments зберігає файли.
shalom send
Надсилає лист: текст у параметрі, у файлі чи зі стандартного входу, плюс вкладення.
shalom reply <id>
Відповідає в тому самому листуванні. --all відповідає всім.
shalom move <id> --to <folder>
Переміщує до вхідних, архіву, спаму чи кошика.
shalom mark <id> --read
Позначає як прочитаний чи ні, із зірочкою чи без.
shalom watch
Чекає нові листи. --exec запускає команду для кожного листа.

Запустіть shalom --help, щоб побачити всі параметри. Усі команди приймають --json, а --as <адреса> вибирає скриньку.
